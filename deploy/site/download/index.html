电脑端工具包怎么用

需要 Python 3.9 以上。解压后在工具包目录里：

python3 -m venv .venv
.venv/bin/pip install -r requirements.txt      # Windows：.venv\Scripts\pip install -r requirements.txt

# 手机「导出全部」的 ZIP → HTML 报告（可调裂缝延长阈值）
.venv/bin/python report.py 全部测点.zip --grow-mm 10

# 两张照片直接对比（结果图写到 out/ 目录）
.venv/bin/python photo_archive.py compare 参考.jpg 本次.jpg -o out

离线查看器 查看器.html 双击用浏览器打开，把导出 ZIP 拖进去即可，不需要联网。
